# ASTRA OFFICE

Offline-first Flutter office-suite bootstrap.

## Current v0.1.0 bootstrap
- Local file picker and recent files
- TXT create/edit/save-as
- DOCX open, plain-text edit, compatibility-mode re-save
- XLSX open/create/edit/save-as
- PPT/PPTX device-viewer handoff
- PDF device-viewer handoff
- GitHub Actions release APK workflow

## Next milestones
- Native rich-text DOCX editor with formatting model
- Formula-aware spreadsheet cell types and multi-sheet tabs
- Native PDF renderer + annotations/signatures
- PPTX parser, slide canvas and element editing
- Autosave/recovery, undo/redo, templates, print/share/export
- Bengali localization

This project intentionally warns when advanced Office formatting cannot be preserved.
